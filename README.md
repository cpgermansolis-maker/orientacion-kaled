# Cuestionario de orientación vocacional — Kaled

Página web con un cuestionario de orientación vocacional hecho para Kaled.
Está publicada con **GitHub Pages** y funciona en cualquier navegador (incluido
Safari del iPhone).

## Enlace público

https://cpgermansolis-maker.github.io/orientacion-kaled/

## ¿Qué hay en este proyecto?

- **`index.html`** — La página que se publica. Es la que abre el enlace de arriba.
- **`cuestionario-vocacional-kaled.html`** — Copia original de respaldo (no se publica).
- **`README.md`** — Este archivo de notas.

La foto y todo el código están dentro del propio `index.html`, así que no hay
archivos sueltos que se puedan perder.

## ¿Cómo actualizar la página si quiero cambiar algo?

1. Edita `index.html` con el cambio que quieras.
2. Guarda y súbelo a GitHub con estos dos comandos:

   ```
   git add -A
   git commit -m "Describe aquí el cambio"
   git push
   ```

3. Espera 1–2 minutos. El enlace se actualiza solo (puede que tengas que recargar
   la página).

> Lo más fácil: pídeselo a Claude Code ("cambia esto en index.html y vuelve a
> publicar") y él hace los tres pasos por ti.
